# KVITY — демо-сайт цветочной студии

Статический сайт (HTML/CSS/JS, без сборки и бэкенда). Mobile-first, 4 языка (RO по умолчанию / EN / UA / RU).

## Структура
```
site/index.html        — разметка
site/css/style.css     — стили и анимации
site/js/config.js      — ВСЕ контакты: номер WhatsApp, телефон, адреса, ссылки, галерея, отзывы, юр. данные
site/js/i18n.js        — все тексты на 4 языках
site/js/main.js        — логика: язык, галерея/лайтбокс, форма → WhatsApp, анимации
site/img/              — фото WebP: <id>-<slug>.webp (большое) и <id>-<slug>-s.webp (превью), og.jpg — превью ссылки
site/fonts/            — шрифты Jost, Cormorant Italic, Montserrat (буквы логотипа), Sacramento (подпись «your happy moments and memories»)
site/v1/               — первая версия сайта (для сравнения): /v1/
site/v6/               — черновик «бутик» (как модный дом: слоновая кость, чёрный, шампань, прямые углы, триптих фото): /v6/. Без своего скрипта, эффекты только в CSS
site/v5/               — черновик «Bloom» (светлый, пастель): /v5/. Орбита фото, выбор настроения (4 цветовые темы), 3D-карусель, бенто, шарики, лента отзывов в 3D; js/fx.js
site/v4/               — черновик «кино» (тёмный, эффекты при прокрутке): /v4/. Как v3, плюс свой js/fx.js (заставка, «влёт» в букву I, лента категорий, курсор, лепестки)
site/v3/               — черновик нового стиля «журнал»: /v3/. Свои index.html и css/, а фото, тексты и логика общие (../img, ../js; window.KV_BASE = "../")
photos-raw/            — исходные фото от владелицы (в git не попадают)
foto/                  — конструктор фото для Алины: https://kvity.ro/foto/ (вход по паролю).
                         Внутри настоящий сайт, её фото перетаскиваются на картинки, подписи букетов правятся на месте,
                         «Готово» сохраняет выбор. Живой сайт не меняет. Сервер: контейнер kvityfoto-web-1 (порт 4100),
                         /opt/kvityfoto (app, data — её фото и state.json, .env — пароль). Выкладка: bash foto/deploy.sh.
                         Локально: node foto/server.js --dev → http://localhost:5600/foto/ (пароль в foto/.env, в git не идёт)
deploy/setup.sh        — установка на сервер (nginx + HTTPS + автообновление)
```

## Как поменять
- **Номер для заявок / телефон / адреса** → `site/js/config.js` (`whatsapp` — только цифры с кодом страны).
- **Тексты** → `site/js/i18n.js`, ключи одинаковые для всех языков.
- **Фото галереи** → сделать `site/img/gNN-<slug>.webp` (до 1280 px) и `site/img/gNN-<slug>-s.webp` (640 px; slug — описание по-румынски латиницей, для Google), добавить `{ id, slug, cat }` в `gallery` в `site/js/config.js` и подпись в `gallery.captions` в `site/js/i18n.js` (для всех 4 языков). Категории: bouquets, xl, baskets, wedding, balloons.
- **Рейтинги и отзывы Google** → `rating`/`reviews` у студий и массив `reviews` в `site/js/config.js`. Только настоящие отзывы, текст дословно (длинные — фрагментом с «…»), имя сокращено.
- **Карты и маршрут** строятся по `lat`/`lng`/`placeId` студий (точные карточки в Google Maps). Карта грузится сама при прокрутке до блока.

## Запуск локально
```bash
python -m http.server 5500 --directory site
```
Открыть http://localhost:5500. С телефона в той же Wi-Fi сети: `http://<IP компьютера>:5500`.

Язык выбирается так: адрес `/en/` или `/ua/` → `?lang=ro|en|ua` → (роботы поисковиков на главной всегда RO) → сохранённый выбор → язык браузера → EN.

**Свои адреса языков (для Google, с 24.11.2026):** `kvity.ro/` — RO, `kvity.ro/en/`, `kvity.ro/ua/`. Страницы `site/en/index.html` и `site/ua/index.html` собираются из `site/index.html` + `site/js/i18n.js`:
```bash
node tools/build-lang-pages.js
```
**Запускать после КАЖДОЙ правки `index.html` или `i18n.js`**, перед коммитом. Вручную эти две страницы не править.

## Публикация — https://kvity.ro (старый адрес kvity.tutormate.site удалён 24.11.2026)
Сайт живёт на сервере Hetzner (95.217.133.58) рядом с TutorMate, в `/var/www/kvity`, отдельный конфиг nginx.
Сервер сам подтягивает изменения из GitHub (`SerhiiDobriev/kvity-site`) каждые 2 минуты, поэтому обновление — это просто:
```bash
git add -A
git commit -m "Обновление сайта"
git push
```
Первичная установка (один раз, в веб-консоли Hetzner от root — команды без спецсимволов, консоль их не портит):
```bash
curl -sL raw.githubusercontent.com/SerhiiDobriev/kvity-site/main/deploy/setup.sh -o /tmp/kvity.sh
bash /tmp/kvity.sh
```
DNS (Namecheap → Advanced DNS): A-запись `kvity` → `95.217.133.58`.

**После правок CSS/JS** увеличь версию в `site/index.html` (`?v=2.1` → `?v=2.2`), чтобы браузеры сразу взяли новые файлы.
